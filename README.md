# GSAP Practice Project

A small frontend animation project built to practice **GSAP (GreenSock Animation Platform)** and explore smooth, interactive web animations.

## 📌 About

This project was created as a hands-on practice project while learning GSAP.

The main focus was understanding how to create and control animations using GSAP, including:

* Basic element animations
* `gsap.to()`
* `gsap.from()`
* `gsap.fromTo()`
* Timelines
* Staggered animations
* Scroll-based animations
* ScrollTrigger
* Text and element transitions
* Background video integration

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* GSAP
* GSAP ScrollTrigger
* Vercel

## 🎯 Purpose

The purpose of this project is to build a strong foundation in GSAP and understand how animation concepts can be applied to real-world frontend interfaces.

This project is mainly focused on **learning, experimentation, and animation practice**.
